# Source Profiling Framework

## Objective

Build reusable profiling utilities to understand VietDist source datasets before ETL development.

## Scope

The framework will profile:

- Row count
- Column metadata
- Data types
- Missing values
- Unique values
- Duplicate records
- Basic validity checks

## Phase 2 Deliverables

- Python profiling utility
- Dataset profiling reports
- Data quality observations
- Data dictionary enrichment
