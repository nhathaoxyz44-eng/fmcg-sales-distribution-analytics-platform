# VietDist Data Profiling

This folder contains profiling reports for the 10 source datasets.

## Profiling Scope

Each dataset report will include:

1. Dataset overview
2. Schema analysis
3. Column profiling
4. Data quality assessment
5. Business rules
6. Warehouse usage considerations

## Sources

- SRC01 Sales Transactions
- SRC02 Sales Target Plan
- SRC03 Customer Master
- SRC04 Product Master
- SRC05 Distributor Orders
- SRC06 Distributor Master
- SRC07 Employee Master
- SRC08 Territory Mapping
- SRC09 Return Transactions
- SRC10 Promotion Program
